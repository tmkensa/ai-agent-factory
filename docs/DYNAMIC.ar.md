# معاينة v0.5 — مصنع الوكلاء الديناميكي

المسار القديم v0.4 مستمر عند عدم استخدام --team، وتبقى حالاته v3 قابلة للاستئناف. المسار الجديد اختياري ويستخدم الحالة v4. هو شبكة استدعاءات نماذج لإنتاج المسودات ومراجعتها، وليس إنشاء جلسات أصلية في Codex أو Antigravity.

    python -m factory.platform team-plan examples/architecture.ar.json --team examples/team-checklist.json --workers 2
    python -m factory.platform --project dynamic-demo run examples/architecture.ar.json --team examples/team-checklist.json --calls 18

اختر auto للتحليل الحتمي التقريبي، single لمنتج واحد مع ثلاث مراجعات إلزامية، multi لتوزيع المعايير على أربعة متخصصين كحد أقصى، أو ملف JSON من المستخدم. الملف يسمح بثمانية متخصصين واعتمادياتهم ومالك واحد لكل معيار. لا يمكن حذف المنفذ أو مراجعات الأمن والاختبارات والتقييم. عدد العمال 1–4. يمكن اختيار نموذج لكل متخصص بواسطة --role-route agent:backup=ollama/model. الإرسال للسحابة يتطلب الموافقة المعروفة.

كل محاولة تُحجز قبل الإرسال. تُحفظ إصدارات المخرجات مع بصماتها ومعرفات مخرجات الاعتماديات. يرجع المعيار الفاشل إلى مالكه المسجل مسبقاً، وتُعاد الأدوار التابعة له والمراجعات الإلزامية، لا الفريق كله. الأخطاء الحرجة غير المصنفة تعود للمنفذ. تُرسل المسودة السابقة وملاحظات التصحيح والاعتماديات الحالية. لا تُقص البيانات بصمت؛ حدود السياق بالبايت لا بالتوكن. التوقف عند تكرار المخرجات والإخفاقات أو استنفاد الميزانية أو جولتي تصحيح. لا تجاوز للبوابة.

أوامر show/resume/approve تعمل على المسار الجديد مع المشروع والنماذج نفسها. show يعرض محتوى المخرجات المحفوظة؛ لا تنشره إذا احتوى على بيانات خاصة. لا تنفيذ للشيفرة أو نشر تلقائي. التحقق من البصمات ليس توقيعاً أمنياً. مولد الخطط بالذكاء الاصطناعي والموصلات الأصلية والتعلم واختبارات Laravel/MySQL والتحليل الدلالي للسياق ليست مكتملة. الاختبارات البرمجية تستخدم محاكاة وليست إثباتاً لجودة النموذج الحقيقي.
