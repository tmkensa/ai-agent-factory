# Contributing / المساهمة

Open an issue describing a reproducible problem or proposed capability. For a pull request, use a separate branch, keep changes focused, update English and Arabic documentation, and add tests. Run `python -m unittest discover -s tests -v`. Never include private logs, credentials, real customer data or local run files. State what was actually tested and what remains unverified. External actions require a separately reviewed authorization design. By submitting contributions you agree to license them under the repository's MIT license.

افتح Issue لوصف المشكلة أو الاقتراح. استخدم فرعًا منفصلًا، وحدّث التوثيق باللغتين وأضف اختبارات. نفّذ الأمر المذكور أعلاه ولا ترفع السجلات الخاصة أو المفاتيح أو بيانات العملاء. وضّح ما اختبرته فعليًا. المساهمات تخضع لترخيص MIT.
